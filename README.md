# Public Cards

Public Cards (public.cards) is a project (in early development)
that seeks to extend the concept of standard
open-data objects, like vcards (and other microformats)
into many other use cases such as:

* shareable website profiles (that the owner can create or another person can create first, then the owner can take ownership of)
* project descriptions (that can be created to define a scope of work and shared with multiple service providers for a quote)
* trading cards (like baseball cards, or like pokemon or magic cards; that are also playable)

The cards represent "source of truth" objects can be long-lasting or single-time use; but are designed to be public.

### Other notes

* Design for web-native, mobile first (phone)
* A card can be (at least) 2-sided
* A card can support images
* A card is stored as versionable human-readable code (ultimately on a blockchain), but can have viewer utilities
* A card can support legal usage terms (DRM); by referencing terms (likely on a blockchain as well)
* Where multiple cards exist describing a single entity, we will need to work through provenance, merging, de-duplication, and authoritative ownership.
